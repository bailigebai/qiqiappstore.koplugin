# v0.1.7 地址分配错误与连接断开恢复验证

用户现象：WebDAVManga ZIP 报 Cannot assign requested address；Legado 下载报 Connection reset by peer。错误发生在商店下载阶段。

已确认的代码缺陷：v0.1.6 下载函数只将 TLS 等待和 timeout 列为可恢复；这两类连接错误会立即退出，没有尝试现有同版本备用官方入口。KOReader 使用的 LuaSocket 还把 ECONNRESET / ECONNABORTED 映射为 closed。

最小改动：这三种错误只作完整字符串、大小写不敏感匹配，复用现有有限 GET 恢复；单来源最多重试一次、多来源每个尝试一次；共用300秒预算。残包关闭/删除，每次wb从头下载；保留镜像选择、同版本大小/SHA256校验。提示保留具体错误与入口，连接失败不再标成超时。没有修改漫画/书源运行代码，也没有强制地址族或添加依赖。

验证：先观察新回归在旧函数失败，再修改通过。Lua5.1/LuaJIT2.1共38套回归通过，包括实际Net wrapper与KOReader socketutil接收器的闭环：普通返回、真实error(reason,0)、残包清理、备用入口恢复、300秒预算耗尽、永久证书/权限/参数错误不重试。独立最终审阅无阻断。32文件ZIP重复构建一致，CRC、Lua语法、模块闭包、私人配置排除检查通过。

安装包在线核验：账号11个项目全部检查；6个项目的7个最新Release ZIP均匿名下载200、大小/SHA256与Release一致、CRC正常、目录无越界。5个无Release。WebDAV独立/组合包和Legado各用固定提交raw与API附件入口再验证，共6次全部一致。原生设备错误未在电脑网络复现，不能断言设备连接错误由插件包、IPv6或资源耗尽引起。

验收：手动覆盖商店至0.1.7并完全退出重启KOReader，刷新，再下载安装ZIP。WebDAV选择独立webdavmanga.koplugin-v0.4.18-20261008-cache-size-fix.zip；书源选择legado.koplugin-v0.10.53-20261008.zip。预期连接短暂失败可自动恢复，失败文件不会用于安装；持续全部入口不可达仍明确报错。

未解决：设备端实际DNS/地址分配/连接断开来源尚无日志，真机最终验收待用户反馈；永久错误不自动绕过。带任意Lua文件行号前缀的异常不作模糊匹配。
