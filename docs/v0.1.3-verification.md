# v0.1.3 发布验证（2026-10-07）

## 原因与范围

用户在下载 Legado Release ZIP 时收到 wantread。KOReader socketutil 将 wantread 标记为 LuaSec TLS 等待超时；v0.1.2 仍使用默认 15 秒连接等待，只延长了 sink 总预算。本次文件下载等待提高到 45 秒，对 wantread、wantwrite、timeout 最多自动重试一次，两次请求共用 300 秒预算。HTTP 错误、证书错误和 sink timeout 不重试，不修改全局默认参数，不切换用户选择的下载来源。

LuaSec 说明：https://github.com/lunarmodules/luasec/wiki/LuaSec-1.0.x
KOReader 参考：https://github.com/koreader/koreader/blob/v2026.07.1/frontend/socketutil.lua

## 已执行

- 新增回归用例在 v0.1.2 失败：第一次 wantread 导致立即退出。
- 修复后验证临时错误后成功、仅一次重试、重新打开文件防止混入残留、共享剩余时间预算、HTTP/证书/总预算错误不重试、失败清理和全局默认值不变。
- 开发项目 tests/run.py：Lua 5.1、LuaJIT 2.1 各 10 组，共 20 组；语法检查通过。
- scripts/check_package.py：两次打包一致，包内 Lua 语法、模块完整性、私人配置排除和令牌扫描通过。
- Legado v0.10.50 Release ZIP 在本机匿名实测下载 HTTP 200，552946 字节，约 4.94 秒，跳转到 release-assets.githubusercontent.com；SHA256 d140b7007571730a55ac5c987a170bae4f85b3aa3759330d0b14e58a91a32cc9。
